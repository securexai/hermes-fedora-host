# Reviewed offline unit allowlist.
#
# Every entry is an explicit `module.Class` or `module.Class.method` target under
# tests/. The pre-push gate (toolbox/run-offline-checks.sh) runs exactly this set
# through tests/run-reviewed-suites.py; it never discovers tests.
#
# The boundary is class-level, not method-level: a `module.Class` entry approves
# the whole class, so it also runs every `test*` method added to that class
# later. `module.Class.method` entries (used for the mixed ssh-key-only class)
# approve one method only. A NEW module or class is not run until it is reviewed
# and added here, so installing a new tool cannot silently widen the offline gate
# into real VM, disk, firmware or host-service work. To keep a class-level entry
# from widening implicitly, review the class's added methods when they change.
#
# Excluded on purpose (see tests/integration_allowlist.txt):
#   test_hermes_lab_disk.LabDiskIntegrationTests
#       real guestfish appliance + qemu-img disk creation/conversion
#   test_hermes_unattended.BootBuildIntegrationTests
#       real ukify/sbverify/dracut UKI build against a host kernel
#   test_hermes_unattended.InstalledGuestfishParserTests
#       installed guestfish stdin parser probe
#   test_hermes_tpm_profile.PackagedDracutIntegrationTests
#       packaged dracut-install + cpio + lsinitrd archive readback
#   test_ssh_key_only.KeyOnlyTests.test_real_sshd_candidate_and_first_value_conflict
#       real /usr/sbin/sshd candidate validation (rest of KeyOnlyTests is unit-only)
#
# test_hermes_unattended.ResticIntegrationTests stays here: it runs the real
# `restic` binary but only against a disposable local repository and synthetic
# data, with --no-cache, no network and no privileged or host-mutating calls.
